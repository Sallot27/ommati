# رفيق الطاعة

تطبيق ويب (Laravel 13) يعمل كتطبيق جوال (PWA) لمرافقة يومية في الطاعة:

- **الأذكار**: أذكار الصباح والمساء والنوم وبعد الصلاة، وحصن المسلم كاملاً، مع عدّاد بالضغط وفضل كل ذكر ومصدره.
- **حفظ القرآن**: ورد يومي بثلاث خطوات (استمعي ← اقرئي والكلمات تختفي تدريجياً ← سمّعي كلمة كلمة)، وربط الآيات، ومراجعة متباعدة (بعد ١، ٢، ٤، ٧، ١٤، ٣٠، ٦٠ يوماً).
- **آية اليوم**: نص الآية بالرسم العثماني، تلاوتها، التفسير الميسّر وتفسير السعدي، و«كيف أعمل بها» من كتاب *تدبّر وعمل*.
- **حديث اليوم**: الحديث مع درجته، وشرحه، وفوائده العملية، ومعاني كلماته من *موسوعة الأحاديث النبوية* (HadeethEnc).
- **المصحف والتلاوات**: المصحف كاملاً، الاستماع لعشرة قرّاء آية آية مع تكرار الآية، وتلاوات السورة كاملة لعادل ريان وإسلام صبحي ومحمد ديبيروف (mp3quran.net)، والتفسير بالضغط على أي آية.
- **المكتبة**: كتب PDF/EPUB تُرفع من لوحة التحكم أو تُرسل/تُحوَّل لبوت تيلغرام.
- **ورد الختمة**: خطة لختم القرآن في مدة تختارها (أسبوع إلى ٣ أشهر)، ورد يومي بالصفحات، وتهنئة عند الختم.
- **أسماء الله الحسنى**: ٩٩ اسماً ثابتة في الكتاب والسنة (على طريقة ابن عثيمين في «القواعد المثلى»): ٨٣ من القرآن، كل اسم مع آية ورد فيها (تم التحقق آلياً من وروده في نص المصحف) وتفسيرها، و١٦ من السنة الصحيحة مع الحديث (موسوعة الأحاديث النبوية أو الموسوعة العقدية في الدرر السنية).
- **أدعية من القرآن**: ٤٦ دعاءً للأنبياء والصالحين بنصها من المصحف.
- **من كلام الأئمة**: نحو ٢٠٠٠ قول لشيخ الإسلام ابن تيمية وابن القيم وابن كثير والسعدي والطبري والبغوي والشنقيطي، مأخوذة من كتاب «تدبّر وعمل» مع الجزء والصفحة، وقول لكل يوم.
- **الأيام الفاضلة**: حسب تقويم أم القرى — الاثنين والخميس، الأيام البيض، عشر ذي الحجة وعرفة، تاسوعاء وعاشوراء، ست شوال، رمضان، والجمعة — كل منها مع حديثه من موسوعة الأحاديث، وتذكير ليلة الصيام.
- **إضافات**: مواقيت الصلاة (أم القرى) والقبلة بالبوصلة، السبحة، تذكيرات بالإشعارات، تكبير الخط، الوضع الداكن، و«رسالة لعمتك» تظهر في الرئيسية.

## مصادر المحتوى

| المحتوى | المصدر |
|---|---|
| نص القرآن | Tanzil (الرسم العثماني، رواية حفص) — مضمّن في `resources/data/quran.json` |
| أرقام الصفحات والأجزاء | مصحف المدينة (عبر fawazahmed0/quran-api) |
| الأذكار | حصن المسلم (عبر osamayy/azkar-db) — مضمّن في `resources/data/adhkar.json` |
| التفاسير وتدبّر وعمل | spa5k/tafsir_api (مأخوذ من quran.com) — يُجلب عند الطلب ويُحفظ |
| الأحاديث وشروحها | HadeethEnc.com API — يُجلب عند الطلب ويُحفظ |
| التلاوات | cdn.islamic.network |
| مواقيت الصلاة | api.aladhan.com (طريقة أم القرى) |

لا يكتب التطبيق أي نص ديني من عنده؛ كل النصوص من هذه المصادر.

## النشر على Laravel Cloud

1. **أنشئ تطبيقاً** في Laravel Cloud واربطه بهذا المستودع (الفرع `main`).
2. **قاعدة البيانات**: أضف قاعدة بيانات (Postgres أو MySQL) للبيئة.
3. **تخزين الكتب**: أضف Bucket (Object Storage)، واختر **«استخدامه كقرص افتراضي»**. (أو سمِّ القرص كما تريد وضع اسمه في `BOOKS_DISK`).
4. **المتغيرات (Environment variables)**:

   ```env
   APP_NAME="رفيق الطاعة"
   APP_LOCALE=ar
   APP_TIMEZONE=Asia/Riyadh

   ADMIN_EMAIL=بريدك
   ADMIN_PASSWORD=كلمة-مرور-قوية

   VAPID_SUBJECT=mailto:بريدك
   VAPID_PUBLIC_KEY=...
   VAPID_PRIVATE_KEY=...

   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_WEBHOOK_SECRET=نص-عشوائي-طويل
   TELEGRAM_ALLOWED_CHAT_IDS=رقم-محادثتك
   ```

   لتوليد مفاتيح VAPID مرة واحدة (على جهازك أو من Commands في Cloud):
   `php artisan webpush:vapid --show` ثم انسخ القيمتين. **لا تغيّرها بعدها** وإلا تتوقف إشعارات الأجهزة المسجلة.

5. **Build commands** (الافتراضية مناسبة):

   ```
   composer install --no-dev
   npm ci --audit false
   npm run build
   php artisan optimize
   ```

   **Deploy commands** (في إعدادات البيئة):

   ```
   php artisan migrate --force
   php artisan app:setup
   ```

   `app:setup` ينشئ حساب لوحة التحكم من `ADMIN_EMAIL/ADMIN_PASSWORD` ويجهز قائمة الأحاديث، وآمن تشغيله مع كل نشر.

6. **فعّل الـ Scheduler** على الـ App compute. هو المسؤول عن إرسال التذكيرات كل دقيقة، وتجهيز آية وحديث اليوم بعد منتصف الليل.
7. انشر (Deploy).

### بوت تيلغرام للكتب

1. أنشئ بوتاً من [@BotFather](https://t.me/BotFather) وضع التوكن في `TELEGRAM_BOT_TOKEN`، ثم انشر.
2. لوحة التحكم ← الإعدادات ← «ربط بوت تيلغرام بالتطبيق».
3. أضف البوت **مشرفاً** في قناتك (يكفي صلاحية نشر الرسائل)، وانشر فيها كتاباً — أو أرسل للبوت رسالة بالخاص.
4. حدّث صفحة الإعدادات واضغط **«سماح»** بجانب القناة/حسابك.
5. بعدها: كل كتاب يُنشر في القناة يُضاف للمكتبة **تلقائياً وبصمت** (لا يرد البوت داخل القناة).
   الكتب القديمة في القناة: حدّدها وحوّلها للبوت بالخاص دفعة واحدة.
   وصف الملف الاختياري: `العنوان | المؤلف | التصنيف`.

> تيلغرام لا يسمح للبوتات بتنزيل ملفات أكبر من **٢٠ ميغا**؛ ارفعها من لوحة التحكم.
> `TELEGRAM_WEBHOOK_SECRET` و`TELEGRAM_ALLOWED_CHAT_IDS` اختياريان الآن.

### لوحة التحكم

`/admin` — رفع الكتب (عدة ملفات مرة واحدة)، كتابة رسالة تظهر لعمتك في الرئيسية، اسمها، أوقات التذكيرات، وإشعار تجريبي.

### على جوال عمتك

افتح الرابط ← أضفه للشاشة الرئيسية (الطريقة في صفحة «أضيفي التطبيق للشاشة») ← افتحه من الأيقونة ← الإعدادات ← «تفعيل التذكيرات».
على الآيفون لا تعمل الإشعارات إلا بعد إضافته للشاشة الرئيسية (iOS 16.4 أو أحدث).

## التشغيل محلياً

```bash
composer install
cp .env.example .env && php artisan key:generate
touch database/database.sqlite && php artisan migrate && php artisan app:setup
npm install && npm run build
php artisan serve
```

الاختبارات: `php artisan test`

إعادة توليد بيانات القرآن والأذكار المضمّنة تمّت بسكربت خارجي من المصادر أعلاه؛ الملفات الناتجة في `resources/data`.
